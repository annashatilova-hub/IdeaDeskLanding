# Прототипы лендинга Idea Desk

Четыре HTML-макета с **одинаковым посылом Idea Desk**, разной подачей — для выбора до правки [lite-istock.tilda.ws](https://lite-istock.tilda.ws/).

## Как открыть

```powershell
# v4 — evidence-first B2B по лучшим приёмам Omnidata
start docs/landing-prototype/index-omnidata-inspired.html

# v3 — стиль текущей Tilda + посыл Idea Desk (рекомендуется для правки live-страницы)
start docs/landing-prototype/index-tilda-style.html

# v1 — упрощённый B2B
start docs/landing-prototype/index.html

# v2 — современный SaaS (другая визуальная подация)
start docs/landing-prototype/index-saas.html
```

## Четыре варианта — когда что брать

| | **v4 `index-omnidata-inspired.html`** | **v3 `index-tilda-style.html`** | **v1** | **v2 SaaS** |
|---|---|---|---|---|
| **Стиль** | Evidence-first enterprise: интерфейс, доказательства, результат | Как ваша Tilda сейчас | Упрощённый B2B | Notion/Linear SaaS |
| **Hero** | Конкретный результат + крупный UI продукта | Синий фон + изометрия | Текст + скрин | Центр + browser frame |
| **Доверие** | Слой доказательств сразу после hero, место под кейс | Полоска свойств | Нет | Product frame |
| **Этапы** | 5 последовательных шагов, istock отделён | Иконки + 3 блока | Timeline | Pipeline 3×2 |
| **Tilda** | Сильнейший вариант по продаже продукта; потребует перестановки блоков | Проще всего перенести в текущую страницу | Черновик | Другой шаблон |

### Рекомендация

- **Хотите сильнее продавать продукт и можете переставить блоки** → ориентир **v4**.
- **Хотите минимально менять текущую Tilda** → ориентир **v3**.
- **v2** — если позже решите сменить шаблон Tilda на более «продуктовый».
- **v1** — быстрый черновик для согласования смысла без привязки к Tilda-блокам.

v4/v1/v2 используют primary продукта `#3669FD`; v3 — цвета текущей Tilda (`#5CA9E8`, `#00AEEF`).

Конкурентный разбор Omnidata (в репозитории idea-desk): `quality/audits/ux/2026/2026-09-22-omnidata-landing-benchmark/report.md`.

## Соответствие блоков v3 → Tilda

| Блок на v3 | Что править на Tilda |
|---|---|
| Синий hero | Cover: тексты Idea Desk, CTA «Оставить заявку», изометрию можно оставить или заменить на скрин |
| Белая полоска 4 пунктов | Тот же блок внизу hero: подписи про платформу / 20 000 ₽ |
| Карусель болей | Карточки с фото: **новые 5 болей**, кнопка → заявка (не «Решить проблему») |
| Ноутбук «Есть решение» | Тот же блок: текст про Idea Desk, скрин/видео idea-desk |
| Иконки в ряд | Заменить 4 иконки PLM на: коллекция → фото → модель → istock |
| «Как это работает» ×3 | Три двухколоночных блока со скринами idea-desk |
| Сравнение Idea Desk / istock | Новый блок или таблица |
| Синий блок цена + форма | 20 000 ₽ = платформа, форма только заявка |

## Что перенести (общее для всех вариантов)

| Блок | Содержание |
|---|---|
| Hero | Idea Desk, H1 про коллекцию → модель, CTA «Заявка» |
| Боли | 5 карточек про старт коллекции |
| Решение | Idea Desk = процесс, не таблица |
| Этапы | 6 шагов (5 + istock) |
| Две системы | Idea Desk vs платформа istock |
| Цена | 20 000 ₽ = **вся платформа**, Idea Desk входит |
| Форма | Только заявка, без «записи на демо» |
| Убрать | Отзывы-заглушки, 6 одинаковых карточек PLM |

## Скрины для вставки

1. Карточка коллекции с этапами (hero / ноутбук)
2. Список идей / проектов
3. Очередь или карточка идеи / согласование
4. Схема «модель → istock» для шага 6
