# Постановка: карта продукта Idea Desk

**Тип:** отдельная страница на Tilda (не замена лендинга `/idea-desk`).  
**Задача лендинга:** за 30–60 сек — «что это и зачем».  
**Задача карты:** за 3–5 мин — «как устроено внутри» — роли, этапы, одна идея от начала до передачи в istock.

**URL (рекомендация):** `https://lite-istock.tilda.ws/karta`  
**Ссылка с лендинга:** пункт меню «Как устроено» или кнопка «Подробная карта» → `/karta`

---

## Принятые решения

| | Решение |
|---|---|
| Аудитория | Продакт, руководитель разработки, IT — кто хочет понять процесс до заявки |
| Формат | Схема + роли + путь одной идеи; без внутренних кодов (CTR, очереди, API) |
| Idea Desk / istock | Две зоны на схеме: до модели — Idea Desk, дальше — istock |
| CTA | «Оставить заявку» → `/idea-desk#request` или форма на странице |
| Не дублировать | Полный текст лендинга; только углубление |

---

## Блок 2 — главная схема (смысл)

**Зона Idea Desk** (светлая):

1. Коллекция / проект  
2. Идеи  
3. Обработка фото  
4. Коммерческая оценка  
5. Согласование модели  
6. Модель готова  

**Зона istock** (тёмная):

7. Производство на фабриках  

Между зонами — стрелка «передача модели».

---

## Блок 3 — роли

| Роль | На карте |
|------|----------|
| Продакт | Создаёт идеи, видит свои предметы, участвует в решении |
| Специалист по фото | Очередь на обработку, загрузка готового фото |
| Специалист по оценке | Оценка, артикул — без аббревиатуры CTR на сайте |
| Руководитель | Все идеи команды, согласование, статусы |

---

## Блок 4 — путь одной идеи

Линейная цепочка (8–9 шагов), пример:

Идея загружена → фото обработано → оценка проставлена → «берём в коллекцию» → модель согласована → статус «готова к передаче» → istock.
