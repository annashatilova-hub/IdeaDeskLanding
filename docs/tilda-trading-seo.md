# SEO и мета-теги страницы `/trading` (Tilda)

HTML-блоки в `tilda-landing/` **не задают** `<title>` и Open Graph. Их меняют **только в редакторе Tilda** для страницы `https://istock.link/trading`.

## Где править в Tilda

1. Войти в проект **istock.link**.
2. Открыть страницу **«Торговые компании»** (alias `/trading`).
3. **Настройки страницы** (шестерёнка или «Page settings») → вкладка **SEO**.

| Поле в Tilda | Зачем | Рекомендация |
|--------------|--------|--------------|
| **Title / Заголовок** | Заголовок вкладки браузера, сниппет Google/Яндекс | Включить ключ: «CRM для тендерного отдела» |
| **Description / Описание** | Meta description в выдаче и частично в Директе | «CRM для тендеров», выгода, CTA |
| **Keywords** | Слабый сигнал | По желанию: тендеры, CRM, Битрикс24, агрегаторы |

4. Там же или в блоке **«SEO и соцсети»** / **Social** (зависит от версии редактора):
   - **og:title** — можно совпадать с Title или чуть короче для соцсетей.
   - **og:description** — совпадать с Description или сокращённый вариант.
   - **og:image** — баннер 1200×630 (логотип + «CRM для тендеров»).

5. **Publish** → проверить исходный код страницы (Ctrl+U): `<title>`, `<meta name="description">`, `<meta property="og:title">`.

## Пример формулировок (Директ + поиск)

**Title (до ~60 символов):**

`CRM для тендерного отдела — iStockLink | торги и закупки`

**Description (до ~160 символов):**

`CRM для тендеров: лента Контур и Seldon, воронка участия, поставщики и КП. Старт за день, без внедрения как у Битрикс24. Торговые компании — от 6 000 ₽/мес.`

**og:title:**

`CRM для тендеров и тендерного отдела — iStockLink`

**og:description:**

`Единая лента закупок, воронка торгов и закупки с поставщиками. Альтернатива доработке CRM под тендеры.`

## H1 на странице vs Title

- **Title** — для поиска и рекламы (может быть длиннее и с ключами).
- **H1** — в блоке `01-hero.html` на Tilda («Система для тендерного отдела» и т.п.). Не обязан дословно совпадать с Title, но **лучше одна тема**: тендерный отдел / CRM для тендеров.

Если в сниппете только «Торговые компании» — в Tilda сейчас, скорее всего, **Title = «Торговые компании»** без description. Замените по таблице выше.

## Яндекс.Директ

- Быстрые ссылки и текст объявления задаются **в кабинете Директа**, не в Tilda.
- URL объявления: `https://istock.link/trading?utm_source=yandex&utm_medium=cpc&utm_campaign=...`
- Тексты объявлений можно синхронизировать с Title/Description, но **UTM и ключи** настраиваются в Директе.

## Превью GitHub Pages

Сборка `npm run build:preview` кладёт блоки в `docs/index.html` **без** meta title страницы `/trading` — это только макет блоков. Эталон SEO — **live Tilda**.
