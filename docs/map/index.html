Роли

Каждый видит своё — без общей «свалки» полей

Idea Desk разделяет работу по ролям, но все шаги остаются частью одной коллекции.

П

Продуктовый менеджер

Создаёт идеи по своим предметам, следит за статусами, участвует в решении «берём / нет».

Л

Продуктовый лид

Видит идеи команды, согласует модели и контролирует готовность коллекции.

Б

Бизнес-лид

Видит портфель компании и участвует в решениях по моделям.

Ф

Фотоспециалист

Очередь на обработку, загрузка готового фото — без лишних полей из других этапов.

О

Специалист по оценке

Коммерческая оценка, артикул, сроки — только то, что нужно для принятия решения.

Д

Дизайнер

Техническая отрисовка модели — графическая часть, когда она нужна.

К

Конструктор

Технические параметры модели.

Р

Руководитель производственного отдела

Идентификация моделей и база лекал после согласования.
