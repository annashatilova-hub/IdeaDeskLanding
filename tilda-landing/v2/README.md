# Idea Desk — лендинг v2 (sage)

Вторая версия лендинга по макету: sage-green палитра, serif-заголовки, 6 блоков.

- **Превью:** `docs/v2/index.html` после `npm run build:v2`
- **GitHub Pages:** `/v2/`

## Блоки (порядок)

| Файл | Содержание |
|------|------------|
| `01-hero.html` | Шапка, hero, макет UI |
| `02-steps.html` | 6 шагов к готовой модели |
| `03-problems.html` | 5 болей |
| `04-systems.html` | Idea Desk + istock |
| `05-result.html` | 3 результата |
| `06-request.html` | Тариф + заявка + подвал |

## На Tilda

1. Создайте страницу **idea-desk-v2** (или замените текущую после согласования)
2. Вставьте 6 блоков T123 по порядку, отступы **0px**
3. Меню Tilda можно заменить на блок `01-hero` (там есть preview-nav) или настроить отдельно
